# 세종철인 훈련허브 — 관리자 매뉴얼 (초보자용)

이 문서는 "코드를 하나도 몰라도" 텍스트 같은 간단한 수정을 직접 할 수 있게 만든 안내서예요.
더 자세한 스크린샷·색상 예시가 있는 버전은 Claude가 만들어준 웹페이지(Artifact) 링크를 참고하세요.

## 0. 처음 한 번만 하면 되는 준비

1. **VS Code** 설치 (무료 코드 에디터) — https://code.visualstudio.com
2. 설치 후 실행 → `파일 > 폴더 열기` → 아래 폴더 선택
   ```
   C:\Users\choco\dev\sejong-triathlon-hub
   ```
   ⚠️ 이 폴더가 진짜예요. `Downloads\준비\기록` 같은 다른 폴더는 예전 복사본이니 거기서 작업하면 안 돼요.

## 1. 전체 흐름 (한 번 이해하면 끝)

```
내 컴퓨터에서 글자 수정 → 저장
        ↓
git으로 GitHub에 올리기 (push)
        ↓
Vercel이 자동으로 감지해서 새로 배포 (1~2분)
        ↓
https://sejong-ironman-hub.vercel.app 에 반영됨
```

## 2. 매번 반복하는 5단계

1. VS Code 열기 (위 폴더가 열려있는 상태)
2. `Ctrl+Shift+F` → 바꾸고 싶은 글자 검색 (예: "훈련허브")
3. 오른쪽에 새 글자 입력하고 "모두 바꾸기" 클릭 (또는 하나씩 클릭해서 수정)
4. 저장 (`Ctrl+S`)
5. VS Code 안에서 터미널 열기 (`Ctrl+\``) 후 아래 3줄을 순서대로 입력:
   ```
   git add -A
   git commit -m "훈련허브를 트레이닝 허브로 변경"
   git push
   ```
6. 1~2분 뒤 실제 사이트를 새로고침해서 확인

## 3. 실전 예시 — "훈련허브" → "트레이닝 허브"

이 글자는 `src/app/page.tsx`, `src/app/TopNav.tsx` 등 총 16개 파일에 흩어져 있어요.
하나씩 다 열 필요 없이 `Ctrl+Shift+F`의 "모두 바꾸기"를 쓰면 전체가 한 번에 바뀌어요.

## 4. 난이도별 가이드

- 🟢 **쉬움 (혼자 해도 됨)**: 화면 문구, 버튼 이름, 안내 문구 같은 순수 텍스트
- 🟡 **중간 (해볼 만함, 조심)**: `globals.css` 안의 색상 코드(`#`으로 시작), 마일리지 가중치 같은 숫자
- 🔴 **어려움 (Claude에게 시키기)**: 새 메뉴/페이지, 데이터베이스 구조, 로그인/인증 로직

## 5. 절대 건드리면 안 되는 것

- `.env` 파일 — 비밀번호·API 키. 잘못 건드리면 로그인 전체가 깨져요 (실제로 겪었던 `sejong2026` 사건 참고).
- `src/lib/db.ts`, `prisma/` 폴더 — 데이터베이스 연결 설정
- `package.json`의 `dependencies` 부분
- `node_modules`, `.next`, `.vercel` 폴더 — 자동 생성되는 것들

## 6. (선택) 올리기 전 내 컴퓨터에서 미리 보기

```
npm run dev
```
브라우저에서 **http://localhost:3010** 열기 (3000번이 아니라 **3010번**이에요!)
확인 후 터미널에서 `Ctrl+C`로 서버 끄기.

## 7. 실수해도 괜찮은 이유

- Git이 모든 변경 이력을 저장해요 — 언제든 예전 상태로 되돌릴 수 있어요.
- Vercel 대시보드(vercel.com) → Deployments에서 예전 배포를 눌러 "Promote to Production" 하면 즉시 롤백돼요.
- 확신 없으면 push 전에 Claude에게 화면 캡처와 함께 물어봐도 돼요.

## 부록 — 명령어 요약

| 명령어 | 하는 일 |
|---|---|
| `git status` | 지금 뭐가 바뀌었는지 확인 |
| `git diff` | 구체적으로 뭐가 바뀌었는지 확인 |
| `git add -A` | 바뀐 것 전부 담기 |
| `git commit -m "설명"` | 담은 것 저장 |
| `git push` | GitHub에 올리기 → 자동 배포 시작 |
| `npm run dev` | 내 컴퓨터에서 미리 보기 (localhost:3010) |
